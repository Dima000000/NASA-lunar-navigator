## Проверка задания

Официальные вкладки Details и Resources задачи Lunar Landing Site Navigator за 2026 год прочитаны. Основные требования реализованы: выбор/сравнение мест и дат, положения Солнца и Земли относительно горизонта с рельефом, оценка видимости, временная шкала и 2D/3D. В этих вкладках нет закрытого списка единственно разрешённых наборов данных. Использованы NASA LOLA, NASA SVS, LROC, JPL NAIF/Horizons; публикации служат источниками фактов и координат, текст и изображения статей не распространяются.

Подача проекта команды, требования конкретного мероприятия, сроки и обязательные материалы остаются отдельной проверкой. Приложение не является продуктом NASA и не подтверждает безопасность реальной посадки, радиоканала или движения.

## Проверки и воспроизводимость

Семь автоматических проверок проходят, включая независимые эталонные положения, физические единицы батареи, медленную зарядку, временные маршруты, уклоны, окна и комплектность данных. Браузерная проверка проходит для посадки, ровера, сравнения, CSV и мобильного экрана без ошибок. Ускоренная интерполяция побитно совпадает с исходной; разница ускоренного расчёта видимого солнечного диска менее 3×10⁻⁸ доли диска.

Подробности, численные таблицы, исходные ответы JPL и ограничения: [SCIENCE_REVIEW](public/research/SCIENCE_REVIEW.md). Источники и обработка: [PROVENANCE](public/data/PROVENANCE.md). Для запуска исходников нужны Node 24, npm ci, npm run start; сборка — npm run build.
