# Технические заметки — Dark Vector

Проект Lunar Landing Site Navigator использует измеренный рельеф NASA LOLA, снимки LROC и эфемериды NASA/JPL. Научные данные и ограничения описаны в README и PROVENANCE.

Геометрическая видимость Земли не гарантирует радиосвязь. Пороги уклона и характеристики ровера — сценарные допущения. Маршруты приближённые; мелкие препятствия могут быть не разрешены исходными данными.

Проверки: 12 автоматических тестов, 4326 сравнений CSV с Horizons, браузерные сценарии и сборка. Проверка отдельного физического слабого ноутбука остаётся задачей команды. Последующее форматирование и разделение renderer — отдельный этап. Финальная конкурсная подача оформляется командой отдельно.
