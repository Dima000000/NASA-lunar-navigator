# Технические заметки — Dark Vector

Над Lunar Landing Site Navigator работали участники Dark Vector: **Andrey Stomma**, **Dmitry Belousov**, **Ivan Ermolaev** и **Gleb Naumkin**. [Список авторов и аккаунты Space Apps](../../AUTHORS.md).

Проект Lunar Landing Site Navigator использует измеренный рельеф NASA LOLA, снимки LROC и эфемериды NASA/JPL. Научные данные и ограничения описаны в README и PROVENANCE.

Геометрическая видимость Земли не гарантирует радиосвязь. Пороги уклона и характеристики ровера — сценарные допущения. Маршруты приближённые; мелкие препятствия могут быть не разрешены исходными данными.

Последние проверки: 22 автоматических теста, 4326 сравнений CSV с Horizons, браузерные сценарии и сборка. [Отчёт об исправлениях Drive](../DRIVE_FIX_REVIEW.md). Проверка отдельного физического слабого ноутбука остаётся задачей команды. Последующее форматирование и разделение renderer — отдельный этап. Финальная конкурсная подача оформляется командой отдельно.
